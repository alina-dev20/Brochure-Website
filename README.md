# Пригласи — сайт студии электронных приглашений

Многостраничный сайт-визитка: каталог шаблонов с фильтрами, живые
демо-приглашения, калькулятор стоимости, заявки в Telegram, тёмная/светлая
тема, SEO-разметка. Стек: **Next.js 16 (App Router) + TypeScript + Tailwind CSS 4**.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка
npm start          # продакшен-сервер
```

## Структура

```
lib/                    ← ВЕСЬ контент правится здесь
  site.ts               название студии, общие настройки
  contacts.ts           контакты менеджеров (Telegram/WhatsApp) — правятся ТОЛЬКО здесь
  pricing.ts            тарифы, допы, наценка за срочность (единственный источник цен)
  occasions.ts          18 поводов: тексты посадочных, акцентные цвета, SEO
  designs.ts            каталог шаблонов (16 шт.)
  demos.ts              конфиги живых демо-приглашений (4 шт.)
  texts.ts              готовые тексты для /texts
  music.ts              подборка треков для /music
  faq.ts                вопросы-ответы
  testimonials.ts       отзывы
app/
  (site)/               страницы витрины с общей шапкой и подвалом
  demo/[slug]/          живые демо — отдельные мини-сайты без шапки
  api/lead/route.ts     приём заявок → Telegram (+email), honeypot, rate limit
  sitemap.ts, robots.ts генерируются автоматически из контент-слоя
components/             компоненты (карточки, калькулятор, форма, демо-движок…)
```

## Как поменять контакты

Все контакты (два менеджера, Telegram и WhatsApp) заданы в `lib/contacts.ts`
и оттуда подтягиваются в шапку-CTA, футер, страницу контактов, плавающую
кнопку, форму заявки и микроразметку. Подписи «Менеджер 1 / Менеджер 2»
меняются там же (поле `label`). Email на сайте не используется намеренно.

## Как поменять цены

Откройте `lib/pricing.ts` и поменяйте числа в `TARIFFS` / `ADDONS` / `URGENCY`.
Цены обновятся везде сразу: страница «Цены», карточки каталога, страницы
шаблонов, калькулятор, оферта и Schema.org-разметка.

## Как добавить новый шаблон

1. Добавьте объект в массив `DESIGNS` в `lib/designs.ts`:

```ts
{
  slug: "moy-dizayn",            // URL: /design/moy-dizayn
  title: "Мой дизайн",
  occasion: "wedding",           // слаг из occasions.ts
  tariff: "standard",            // цена возьмётся из pricing.ts
  style: "minimal",              // minimal|classic|bright|kids|floral|retro
  features: ["animation", "music", "timer", "rsvp"],
  description: "…", editable: ["…"], fixed: ["…"],
  popularity: 50, isNew: true,
  demoSlug: "tishina",           // какое живое демо открывать (или уберите поле)
  preview: {                     // генеративное превью
    from: "#efe9df", to: "#ddd2c0", ink: "#3d372c",
    variant: "arch",             // arch|lines|confetti|star|wave|frame
    caption: "А & Б", sub: "12 июня",
  },
}
```

2. Всё. Карточка в каталоге, страница `/design/…`, фильтры, «похожие дизайны»,
   OG-картинка и sitemap подхватятся автоматически.

Чтобы у шаблона было **собственное живое демо**, добавьте конфиг в
`lib/demos.ts` (скопируйте существующий и поменяйте тему/тексты/дату) и укажите
его `slug` в поле `demoSlug` шаблона. Демо-движок (`components/DemoInvitation.tsx`)
сам построит обложку, таймер, галерею, тайминг, карту, дресс-код, RSVP и музыку.

### Фото шаблонов

Превью карточек — фотографии из `/public/templates/*.webp` (Unsplash,
свободная лицензия; источник указан в футере). У каждого дизайна в
`designs.ts` есть поле `photo: { src, alt }`; если его убрать, карточка
покажет генеративное превью (рисуется кодом).

Заменить/добавить фото:

1. Положите вертикальный WebP (рекомендуется 720×1280) в `public/templates/`,
   имя файла = слаг дизайна.
2. Укажите `photo: { src: "/templates/<слаг>.webp", alt: "описание" }` у дизайна.
3. Пересоздайте blur-заглушки (нужен macOS `sips`):
   `cd public/templates && python3 ../../scripts/gen-blur.py`
   — скрипт перезапишет `lib/blur-data.ts`.

Не берите изображения с чужих сайтов-конкурентов: используйте стоки со
свободной лицензией (Unsplash, Pexels) и сохраняйте файлы локально.

## Заявки: как подключить Telegram-группу (инструкция без программирования)

Заявки с формы приходят в закрытую Telegram-группу отформатированным
сообщением (имя, контакт, повод, шаблон, дата, комментарий с суммой из
калькулятора, время и страница отправки) с кнопкой **«Написать клиенту»** —
прямой ссылкой на его Telegram или WhatsApp.

**Шаг 1 — создать бота (2 минуты).**
Откройте Telegram, найдите **@BotFather**, отправьте команду `/newbot`.
Придумайте имя (например «Заявки Пригласи») и логин (например
`priglasi_leads_bot`). BotFather пришлёт **токен** — длинную строку вида
`1234567890:AA...`. Скопируйте её, никому не показывайте.

**Шаг 2 — создать группу и добавить туда бота.**
Создайте обычную группу, добавьте в неё обоих менеджеров
(@alino4kaa_14 и @konkretniysihs) и вашего нового бота (по логину).

**Шаг 3 — узнать ID группы.**
Добавьте в ту же группу бота **@getidsbot** — он сразу напишет сообщение,
где будет `chat id` группы (число, начинается с `-100`). Запишите его и
удалите @getidsbot из группы.

**Шаг 4 — вписать ключи.**
В папке проекта скопируйте файл `.env.example` в файл с именем `.env.local`
и вставьте значения:

```
TELEGRAM_BOT_TOKEN=сюда_токен_из_шага_1
TELEGRAM_CHAT_ID=сюда_id_из_шага_3
```

Если сайт задеплоен на Vercel — добавьте эти же две переменные на vercel.com:
проект → Settings → Environment Variables, затем нажмите Redeploy.

**Проверка:** отправьте тестовую заявку с сайта — в группе появится сообщение.

Пока переменные не заполнены, форма работает в дев-режиме: заявка печатается
в консоль сервера и пользователь видит экран «спасибо».

### Архив заявок в Google Таблице (по желанию)

1. Создайте пустую Google Таблицу, первой строкой впишите заголовки:
   `Дата | Имя | Контакт | Мессенджер | Повод | Шаблон | Дата события | Комментарий | Страница | Статус`.
2. В меню таблицы: Расширения → Apps Script. Замените код на:

```js
function doPost(e) {
  const row = JSON.parse(e.postData.contents).row;
  SpreadsheetApp.getActiveSpreadsheet().getActiveSheet().appendRow(row);
  return ContentService.createTextOutput("ok");
}
```

3. Нажмите «Начать развёртывание» → «Новое развёртывание» → тип
   «Веб-приложение», доступ — «Все». Скопируйте выданный URL.
4. Впишите его в `.env.local`: `SHEETS_WEBHOOK_URL=этот_URL`.

Колонка «Статус» остаётся пустой — менеджеры заполняют её вручную
(например «ответили», «оплачено») и по таблице считают конверсию.

### Надёжность

- Если Telegram недоступен, пользователь видит сообщение с прямыми ссылками
  на менеджеров — заявка не теряется; ошибка пишется в лог сервера.
- Защита от спама: скрытое honeypot-поле + не больше 5 заявок в час с одного IP.
- Форма не отправляется без согласия на обработку персональных данных.
- Токен бота используется только на сервере (API route) и не попадает в браузер.

## Как подключить домен

1. Задеплойте на Vercel: `npx vercel` (или импортируйте репозиторий на vercel.com).
2. В настройках проекта Vercel → Domains добавьте домен и пропишите у
   регистратора DNS-записи, которые покажет Vercel (A `76.76.21.21` или CNAME
   `cname.vercel-dns.com`).
3. Установите `NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru` в переменных
   окружения — метатеги, sitemap и Schema.org начнут использовать боевой адрес.

## Метрика

Задайте `NEXT_PUBLIC_YM_ID` (номер счётчика Яндекс.Метрики). Цели, которые
шлёт сайт: `lead_submit` (отправка формы) и `messenger_click` (клик по
мессенджеру) — создайте их в Метрике как JavaScript-события.

## Прочее

- Тексты юридических страниц (`/policy`, `/oferta`) — шаблоны: замените
  реквизиты в фигурных скобках и согласуйте с юристом.
- Название студии и контакты — в `lib/site.ts`.
- Тема (светлая/тёмная) переключается в шапке, выбор хранится в localStorage,
  инициализация — до первой отрисовки (без вспышки).
- Анимации отключаются при `prefers-reduced-motion`.
