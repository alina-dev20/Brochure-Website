# Design: сайт студии электронных приглашений «Пригласи»

Дата: 2026-08-03. ТЗ пользователя исчерпывающее и принимается как утверждённый спек;
здесь зафиксированы только решения, оставленные на усмотрение исполнителя.

## Принятые решения

- **Имя студии (заглушка):** «Пригласи» — легко заменить в `lib/site.ts`.
- **Стек:** Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 (CSS-токены через `@theme`).
- **Анимации:** CSS + IntersectionObserver (компонент `Reveal`) вместо Framer Motion —
  меньше JS-бандл, лучше Lighthouse. `prefers-reduced-motion` уважается глобально.
- **Шрифтовая пара:** Manrope (гротеск, кириллица) + Cormorant (акцидентная антиква,
  кириллица) через `next/font/google` — self-hosted, без FOUT.
- **Палитра:** тёплая «бумажная» база (light `#F7F5F1` / dark `#121110`) + акцент,
  задаваемый CSS-переменной `--accent`, у каждого повода свой оттенок (в `occasions.ts`).
- **Превью шаблонов:** генеративные (CSS/SVG мини-макеты приглашений с анимацией),
  а не стоковые картинки — нет проблем с лицензиями, нулевой вес, «живой» вид.
  Реальные превью подключаются заменой в `designs.ts`.
- **Демо:** один конфигурируемый движок `DemoInvitation` + 4 конфига в `lib/demos.ts`
  (свадьба, детский ДР, юбилей 50, корпоратив НГ). Музыка — генеративный эмбиент
  через WebAudio (без аудиофайлов), включается только по клику.
- **Маршрутизация:** route group `app/(site)` с общим Header/Footer;
  `app/demo/[slug]` — вне группы, без шапки (приглашение = отдельный мини-сайт).
- **Заявки:** `/api/lead` → Telegram Bot API (env `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`),
  дубль на email через Resend (опционально, env `RESEND_API_KEY`). Honeypot-поле +
  in-memory rate limit (5 заявок/час с IP).
- **Тема:** класс `.dark` на `<html>`, инлайн-скрипт в `<head>` до первой отрисовки
  (нет вспышки), выбор в `localStorage`.
- **Каталог:** клиентские фильтры, состояние в query-параметрах через
  `router.replace(..., {scroll:false})`, восстановление из URL при загрузке.
- **URL сайта:** env `NEXT_PUBLIC_SITE_URL` (заглушка `https://priglasi.example`).
